# Algorithms & Data Structures

Репозиторий с решениями университетских задач по алгоритмам и структурам данных на языке C

---

## Темы, которые покрывает репозиторий

- массивы и строки
- сортировки и пользовательские компараторы
- стек, очередь, дек
- бинарная куча
- хеш-таблицы
- деревья, AVL-дерево, treap
- DFS и проверка свойств графов
- кратчайшие пути: Dijkstra, Bellman–Ford
- бинарный поиск по ответу
- жадные алгоритмы
- поиск циклов
- комбинаторика
- динамическое программирование / алгоритм Кадане

---
